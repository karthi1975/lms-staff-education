# Quick Start: 120-Minute Endurance Test

## Run the Test NOW

### Visual Mode (Watch in Browser)
```bash
./run-endurance-test.sh
```

### Background Mode (No Browser)
```bash
./run-endurance-test-headless.sh
```

## What You'll See

Every ~8 minutes, one complete iteration tests:
- ✅ Dashboard
- ✅ Course Management  
- ✅ User Management
- ✅ Module Chat with AI responses
- ✅ Content sections
- ✅ Module management
- ✅ Settings

## Expected Results

- **Duration**: 120 minutes
- **Iterations**: ~15 iterations
- **Chat Questions**: ~150 total (10 questions per iteration)
- **Delays**: 5 seconds between every action

## Stop Anytime

Press `Ctrl+C` to stop the test gracefully.
