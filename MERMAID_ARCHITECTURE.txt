## Architecture Overview

### Multi-Channel Interface
- **WhatsApp**: Primary channel for learner interactions via Twilio
- **Admin Portal**: Web-based management interface for courses, content, and users
- **RESTful APIs**: Backend services for both channels

### Three-Database Strategy
- **PostgreSQL**: Transactional data (users, courses, enrollments, sessions, progress)
- **Neo4j**: Graph database for learning paths, prerequisites, and relationships
- **ChromaDB**: Vector database for RAG-powered semantic search and embeddings

### AI & RAG Pipeline
- **Document Processing**: Handles PDF, DOCX, and OCR extraction
- **AI Classification**: Auto-categorizes content using Vertex AI
- **Vector Embeddings**: Converts content to embeddings for semantic search
- **RAG Service**: Retrieves relevant context for AI-powered responses

### Key Services
- **Orchestrator**: Coordinates message flow between WhatsApp, sessions, RAG, and coaching
- **Authentication**: JWT-based auth with bcrypt password hashing
- **Session Management**: 24-hour TTL for conversation context
- **Quiz Service**: Enforces 70% pass threshold, maximum 2 attempts
- **Coaching Service**: Delivers time-based nudges and progress reflections

### Recent Enhancements
- Async file processing to prevent UI freezing
- Bulk upload capabilities for course content
- Limited OCR (5 pages) for classification
- Course content management with metadata tracking

### External Integrations
- **Vertex AI**: Google's gemini-1.5-flash for LLM and embeddings
- **Moodle LMS**: Placeholder for future course content import
- **Twilio**: WhatsApp Business API integration
